# Herbal Formula Completion

Code and aggregated data for reproducing the manuscript figures and tables.

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/inseong101/HerbalFormulaCompletion/blob/main/Run_analysis_in_Colab.ipynb)

## Run

```bash
pip install -r requirements.txt
python analysis.py
```

Outputs are saved in `figures/` and `tables/`.

The default analysis uses only the small aggregated files in `data/`. Recipe1M and the Korean medicine textbook files are not required to reproduce the manuscript figures.
