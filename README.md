# HerbalFormulaCompletion

Code and data for comparing ingredient recommendation in herbal formulas and food recipes.

[Open in Google Colab](https://colab.research.google.com/github/inseong101/HerbalFormulaCompletion/blob/main/Colab.ipynb)

Run the notebook cells in order to reproduce preprocessing, Table 1, and Figures 1–5 from the input data.

| File or folder | Contents |
|---|---|
| `Colab.ipynb` | Step-by-step analysis and displayed results |
| `run.py` | Analysis and figure-generation code |
| `data/` | Input datasets and herbal display names |
| `figures/` | Manuscript figures |

Herbal formula data were provided by the Korea Institute of Oriental Medicine through the Korean Public Data Portal. Food recipe data came from Recipe1M, with ingredient preprocessing based on Inverse Cooking.

See [data sources and download instructions](data/README.md) for the five herbal datasets, Recipe1M access, and input-file checksums.
